# Vue 3 + Vite + Bootstrap

Многофункциональный инструмент для личной продуктивности и планирования.

# Этот проект представляет собой комплексное приложение, которое объединяет в себе несколько полезных инструментов:

Заметки: Вкладка для создания, редактирования и хранения личных заметок.
Текстовый редактор: Простой, но функциональный текстовый редактор для быстрого набора и форматирования текста.
Счётчик: Примитивный счётчик с возможностью прибавления, вычитания и умножения на 5.
Погода: Вкладка, где пользователь может ввести название города и получить информацию о текущей погоде, включая влажность, температуру, скорость ветра, атмосферное давление, часовой пояс и прогноз на ближайшие дни.

# Проект использует Vue 3 и Bootstrap для создания удобного и отзывчивого пользовательского интерфейса. Он запускается с помощью npm:

- Клонируйте репозиторий проекта
- Перейдите в директорию проекта
- Установите зависимости с помощью команды npm install
- Запустите проект командой npm run dev
- Откройте приложение в браузере

Это приложение предназначено для повышения личной эффективности и организованности, предоставляя пользователям набор полезных инструментов в одном месте.
